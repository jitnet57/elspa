================================================================================
🎯 API 엔드포인트 (9개)
================================================================================

1. GET    /api/network-edges                    - 모든 엣지 조회 (필터 지원)
2. POST   /api/network-edges                    - 새 엣지 추가 (양방향 옵션)
3. GET    /api/network-edges/{edge_id}          - 엣지 상세 조회
4. PUT    /api/network-edges/{edge_id}          - 엣지 수정 (양방향 자동 업데이트)
5. DELETE /api/network-edges/{edge_id}          - 엣지 삭제 (양방향 함께 삭제)
6. GET    /api/network-edges/source/{source_id} - 출발 노드 기준 조회
7. GET    /api/network-edges/target/{target_id} - 도착 노드 기준 조회
8. POST   /api/network-edges/batch              - 일괄 추가 (트랜잭션)
9. GET    /api/nodes/{node_id}/importance       - 노드 중요도 계산

================================================================================
✨ 주요 기능
================================================================================

1. 양방향 관계 자동 생성
   - is_bidirectional=true → 역방향 엣지 자동 생성
   - reverse_edge_id로 양방향 참조 유지

2. 관계 강도 유지 (1-5)
   - 양방향 엣지: 동일한 강도 유지

3. 트랜잭션 처리
   - 일괄 추가 (batch) 시 일관성 보장

4. 필터링 & 검색
   - 다양한 필터 옵션 지원

5. 노드 중요도 분석
   - in_degree, out_degree, avg_strength 계산

6. 성능 최적화
   - 복합 인덱스: (source_id, target_id)
   - O(log N) 조회 성능
