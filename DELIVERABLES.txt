🎯 3가지 핵심 함수
================================================================================

1️⃣ calculate_commission(booking) → Decimal
   ─────────────────────────────────────────
   목적: 예약의 플랫폼 수수료(커미션) 계산
   
   규칙:
   • 기본: total_price × 25%
   • 취소/환불: 0%
   • 반환: 항상 >= 0
   
   사용:
   commission = calculate_commission(booking)
   
   예시:
   commission = calculate_commission(Booking(total_price=5000))
   # 반환: Decimal(1250)  # 5000 × 25%


2️⃣ auto_create_settlement(booking, db, created_by) → CompanySettlement
   ────────────────────────────────────────────────────────────────────
   목적: 예약의 지급 방식(payment_from)에 따라 자동 정산 생성
   
   3가지 규칙:
   ┌──────────────────────────────────────────────────┐
   │ Rule 1: payment_from='guest'                      │
   │ → status='pending', recovery_rate=80%             │
   │ → 손님 외상 (회수 불확실)                      │
   │                                                  │
   │ Rule 2: payment_from='company'                    │
   │ → status='waived', recovery_rate=0%              │
   │ → 회사 정산 제외 (정산 안함)                    │
   │                                                  │
   │ Rule 3: payment_from='credit'                     │
   │ → status='pending', recovery_rate=100%            │
   │ → 신용카드/선지급 (나중 회수)                   │
   └──────────────────────────────────────────────────┘
   
   사용:
   settlement = auto_create_settlement(booking, db, created_by='system')
   
   예시 (Rule 1):
   booking.payment_from = 'guest'
   settlement = auto_create_settlement(booking, db)
   # settlement.recovery_rate = 80%
   # settlement.net_settlement = 2750 (5000 × 80%) - (5000 × 25%)


3️⃣ bulk_settle_monthly(year, month, db, company_id, settled_by) → List[CompanySettlement]
   ────────────────────────────────────────────────────────────────────────────────────────
   목적: 월간 정산 일괄 처리 (approved → settled)
   
   동작:
   1. 대상 정산 조회 (approved 상태만)
   2. 지급일 계산 (월 마지막 날)
   3. 상태 전환 (approved → settled)
   4. 자동 입력 (payment_date, paid_by)
   5. DB 저장 및 반환
   
   사용:
   result = bulk_settle_monthly(2026, 6, db, settled_by='admin')
   
   반환:
   [
     CompanySettlement(id=1, status='settled', net_settlement=2750),
     CompanySettlement(id=2, status='settled', net_settlement=3750),
     ...
   ]
