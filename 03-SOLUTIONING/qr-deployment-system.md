## 1. QR 코드 종류 & 용도

### 1.1 3가지 QR 코드 유형

```
┌─────────────────────────────────────────────────────────────┐
│                    3가지 QR 코드                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ 1️⃣  고정 QR (Static) - 매장 설치용                          │
│   ├─ Admin QR: https://admin.elspa.com/setup?qr=static     │
│   ├─ User QR:  https://app.elspa.com/download?qr=static    │
│   ├─ Staff QR: https://staff.elspa.com/join?qr=static      │
│   └─ 용도: 매장 벽/카운터에 인쇄 (영구 배치)               │
│   └─ 권한: 역할 자동 선택 페이지로 이동                     │
│                                                             │
│ 2️⃣  일회용 QR (Single-Use) - 신입 직원 온보딩              │
│   ├─ 생성: Admin이 "새 직원 추가" → QR 생성                 │
│   ├─ URL: https://staff.elspa.com/auth/qr?token=jwt123     │
│   ├─ 유효기간: 72시간 (또는 1회 사용)                      │
│   └─ 용도: 첫 로그인 시만 유효                              │
│   └─ 자동: 권한 자동 할당 (직원 정보 프리필)                │
│                                                             │
│ 3️⃣  임시 QR (Temporary) - 고객 공유용                      │
│   ├─ 생성: User가 "친구에게 공유" → QR 생성                │
│   ├─ URL: https://app.elspa.com/referral?code=abc123       │
│   ├─ 유효기간: 7일                                          │
│   └─ 할인: 친구 등록 시 양쪽에 크레딧 제공                  │
│   └─ 추적: referral_code로 마케팅 분석                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 각 PWA별 QR 전략

```
📍 Admin PWA (admin.elspa.com)

QR 코드:
- 주소: https://admin.elspa.com/qr/display
- 장소: 관리자실/오피스 벽
- 스캔: 매니저 → 로그인 페이지 (직원 이메일로 로그인)
- 또는: QR 생성 화면에서 직원별 일회용 QR 만들기

QR에 포함된 정보:
├─ base64 로고 (ElSpa 아이콘)
├─ 복사 가능한 URL (수동 입력 옵션)
├─ 설명: "ElSpa Admin - 관리자 시스템"
└─ 스캔 후: "설치하시겠습니까?" 또는 "이미 설치됨 (열기)"

---

📍 User PWA (app.elspa.com)

QR 코드:
- 주소: https://app.elspa.com/qr/download
- 장소: 매장 입구, 카운터, 메뉴판
- 스캔: 고객 → 예약 페이지로 직접 이동
- 프로모션: "QR 스캔 후 첫 예약 10% 할인"

QR에 포함된 정보:
├─ referral_code (자동 생성, UTM tracking)
├─ 매장 정보 (지점명, 전화번호, 주소)
├─ 서비스 목록 (상위 3개)
└─ 스캔 후: 자동으로 "예약 페이지"로 이동 (로그인 또는 회원가입)

---

📍 Staff PWA (staff.elspa.com)

QR 코드:
- 주소: https://staff.elspa.com/qr/join (고정 - 역할 선택)
- 주소: https://staff.elspa.com/qr/invite?token=xyz (일회용 - 직원용)
- 장소: 직원실, 직원 교육 자료
- 스캔: 
  * 고정 QR → 역할 선택 페이지 (테라피스트/드라이버)
  * 일회용 QR → 자동 로그인 (권한 자동 할당)

QR에 포함된 정보:
├─ 직원 이름 (일회용만)
├─ 지점명 (일회용만)
├─ 역할 (일회용만)
└─ 만료 날짜 (일회용만)
```

### 2.2 Backend API: QR 생성 & 검증

```typescript
// 고정 QR (Static) - Admin
GET /api/qr/static/admin
→ {
    url: "https://admin.elspa.com/qr/static",
    base64: "data:image/png;base64,...",
    type: "static",
    scope: "admin"
  }

// 일회용 QR (Single-Use) - Staff
POST /api/qr/single-use/staff
Body: {
  staffName: "박영희",
  role: "therapist",  // or "driver"
  expiryMinutes: 4320,  // 72 hours
  maxScans: 1
}
→ {
    qrCode: {
      url: "https://staff.elspa.com/auth/qr?token=jwt_token_123",
      base64: "data:image/png;base64,...",
      expiresAt: "2026-05-06T10:30:00Z"
    },
    token: "jwt_token_123",
    createdAt: "2026-05-05T10:30:00Z"
  }

// QR 스캔 로그 (분석)
GET /api/analytics/qr-scans?period=weekly
→ {
    staticScans: {
      admin: 15,
      staff: 8,
      user: 42
    },
    singleUseScans: {
      successful: 3,
      expired: 2,
      failed: 1
    },

  }
```

## 4. QR 코드 보안 & 검증

### 4.1 일회용 QR 토큰 구조

```typescript
// JWT 토큰 (일회용 QR에 인코딩)
{
  header: {
    alg: "HS256",
    typ: "JWT"
  },
  payload: {
    sub: "qr_token",
    type: "single_use_login",  // 타입
    staffId: "staff_12345",     // 직원 ID
    staffName: "박영희",         // 이름
    role: "therapist",          // 역할
    branchId: "branch_001",     // 지점
    iat: 1714871400,            // 발급 시간
    exp: 1714960400,            // 만료 시간 (72시간 후)
    maxScans: 1,                // 최대 스캔 수
    scansUsed: 0,               // 사용된 스캔 수
    nonce: "random_uuid"        // 재사용 방지
  },
  signature: "..."
}

검증 로직:
1. JWT 서명 확인 (위조 방지)
2. exp 확인 (유효기간 체크)
3. scansUsed < maxScans 확인
4. nonce 확인 (재사용 방지, Redis)
5. 검증 성공 시 scansUsed++ (DB 업데이트)
```

### 4.2 QR 코드 본인 확인 (2단계)

```
일회용 QR 스캔 후:

1️⃣  QR 토큰 검증 (위조 방지)
    └─ JWT 서명 확인, 유효기간 체크

2️⃣  추가 본인 확인 (선택사항)
    ├─ SMS 인증 (직원 휴대폰)
    │  "ElSpa 로그인 인증: 123456"
    ├─ 이메일 확인 (직원 이메일)
    │  "[확인 링크]"
    └─ 관리자 승인 (특수한 경우)
       "Admin이 로그인 승인했습니다"

권한에 따라:
- 테라피스트: SMS 필수 (개인정보 보호)
- 드라이버: SMS 필수 (GPS 추적 권한)
- 임시 스태프: SMS + Admin 승인
```

## 5. QR 코드 마케팅 & 분석

### 5.1 고객 QR 추적 (UTM)

```
User PWA QR에 포함된 정보:

기본 URL:
https://app.elspa.com/download?qr=static

UTM 파라미터 자동 추가:
?utm_source=qr                    (출처: QR 코드)
&utm_medium=physical              (매체: 물리 QR)
&utm_campaign=in_store_promotion  (캠페인: 매장 프로모션)
&utm_content=entrance             (위치: 입구)
&referral_code=abc123             (추천 코드)

분석 데이터:
- QR 스캔 수: 월 500회
- 설치율: 45% (스캔 후 설치)
- 예약 전환율: 28% (설치 후 예약)
- 평균 지출: ₩95,000 (QR 고객)

비교:
- 유기 방문: ₩75,000 평균
- QR 고객 높음: 신규 고객 + 프로모션

분석 대시보드:
┌──────────────────────────────────────┐
│ 📊 QR 코드 성과 (이번 달)             │
├──────────────────────────────────────┤
│                                      │
│ 📱 스캔 수: 432회 (+12% vs 저달)     │
│ ├─ Admin QR: 48회                   │
│ ├─ Staff QR: 15회                   │
│ └─ User QR: 369회                   │
│                                      │
│ 📥 설치 수: 194회 (45% 설치율)      │
```

## 8. 기술 구현

### 8.1 QR 코드 생성 라이브러리

```typescript
// Frontend: QR 코드 표시
import QRCode from 'qrcode.react';

function QRDisplay({ url, size = 256 }) {
  return (
    <QRCode
      value={url}
      size={size}
      level="H"  // 높은 오류 정정
      includeMargin={true}
      renderAs="canvas"
    />
  );
}

// Backend: QR 코드 생성 및 저장
import QRCode from 'qrcode';

async function generateQR(url: string): Promise<string> {
  try {
    const qrDataUrl = await QRCode.toDataURL(url, {
      errorCorrectionLevel: 'H',
      type: 'image/png',
      width: 512,
      margin: 2,
      color: {
        dark: '#000000',
        light: '#FFFFFF'
      }
    });
    return qrDataUrl;
  } catch (err) {
    console.error('QR 생성 실패', err);
    throw err;
  }
}

// API: QR 다운로드
app.get('/api/qr/download/:qrId', async (req, res) => {
  const { qrId } = req.params;
  const qrRecord = await QRCode.findById(qrId);
  
  res.setHeader('Content-Type', 'image/png');
  res.setHeader('Content-Disposition', `attachment; filename="qr_${qrId}.png"`);
  res.send(Buffer.from(qrRecord.base64, 'base64'));
});
```
