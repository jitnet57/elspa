## 📊 STANDUP ESCALATION DECISION TREE

### **If Track A has blockers:**
```
Is partner unresponsive (>24h)?
├─ YES: Escalate to phone call + LinkedIn
├─ NO: Wait, send reminder email
```

### **If Track B has low conversion (<20%):**
```
Is conversion low (calls made but few demos)?
├─ YES: Adjust script, increase call volume, change time slots
├─ NO: Continue current approach
```

### **If Track C has detractors (NPS <6):**
```
Is detractor NPS <4?
├─ YES: Immediate CEO + CS 1:1 call (within 1 hour)
├─ NO: CS Lead phone call (within 4 hours)
```
