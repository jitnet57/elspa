## 🔴 TRACK C: NPS Data Collection & AI Preparation

### Monday, May 29
- [ ] Design NPS survey (SMS format)
  - [ ] Question 1: "How likely (1-10) to recommend us?" [SMS]
  - [ ] Question 2: "What's the main reason?" [SMS or link to form]
  - [ ] Incentive: "Reply + entered for ₱500 credit"

- [ ] Set up SMS deployment system
  - [ ] Tool: Twilio, AWS SNS, or local SMS provider
  - [ ] Database: Connect to customer list (1,800 records)
  - [ ] Test: Send sample SMS to team

### Wednesday, May 31
- [ ] Deploy NPS survey to first batch (300-400 customers)
  - [ ] Wave 1: Send SMS 
  - [ ] Monitor: Response rate target 40%+ (120 responses)
  - [ ] Log all responses to database

- [ ] Start data analysis template
  - [ ] Calculate NPS score (promoters 9-10, detractors 0-6)
  - [ ] Segment: Detractors / Neutrals / Promoters
  - [ ] Extract reasons (text parsing)

### Friday, June 2
- [ ] Collect & analyze first 200+ responses
  - [ ] NPS score: Likely 5-15 (low, pre-intervention baseline)
  - [ ] Segment breakdown: ~20% promoters, ~25% neutral, ~55% detractors
  - [ ] Top reasons for churn (extract from text)

- [ ] Begin AI model development
  - [ ] Gather 12 months historical data:
    - Visit dates/times
    - Spend per visit
    - Therapist assigned
    - Booking cancellations
    - Any reviews/feedback
  - [ ] Label: Who churned vs. stayed
  - [ ] Start model training (Python/TensorFlow)

### Success Metrics
- ✅ 200-300 NPS responses collected
- ✅ Customer segmentation complete
- ✅ Baseline churn rate documented (40%)
- ✅ AI model training started
