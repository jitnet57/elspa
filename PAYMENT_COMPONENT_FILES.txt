PAYMENT METHOD TYPES SUPPORTED
================================================================================

The component supports 5 payment methods:

1. 💳 card
   - Name: Credit/Debit Card
   - Reference Required: No (optional)
   - Duplicates Allowed: Yes
   - Icon: 💳
   
2. 💵 cash
   - Name: Cash
   - Reference Required: No
   - Duplicates Allowed: No (1 only)
   - Icon: 💵

3. 📱 gcash
   - Name: GCash
   - Reference Required: Yes (transaction ID)
   - Duplicates Allowed: Yes
   - Icon: 📱

4. 🏦 bank_a
   - Name: Bank A Transfer
   - Reference Required: Yes (bank reference)
   - Duplicates Allowed: Yes
   - Icon: 🏦

5. 🏦 bank_b
   - Name: Bank B Transfer
   - Reference Required: Yes (bank reference)
   - Duplicates Allowed: Yes
   - Icon: 🏦

Amount Validation:
  ✓ requireExactMatch: true (payment total must equal invoice total)
  ✓ allowZeroAmount: false (0 payment not allowed)
  ✓ allowPartialPayment: false (must pay exact amount)
  ✓ maxAmount: 999,999,999

Payment Method Validation:
  ✓ card: can have multiple
  ✓ cash: only 1 allowed
  ✓ gcash: can have multiple
  ✓ bank_a: can have multiple
  ✓ bank_b: can have multiple

Reference Number:
  ✓ card: optional
  ✓ cash: not needed
  ✓ gcash: required (8-12 digits)
  ✓ bank_a: required (6-20 alphanumeric)

USAGE EXAMPLE
================================================================================

import { PaymentMethodInput, PaymentMethodData } from '@/components/PaymentMethodInput';
import { useState } from 'react';

export function CheckoutPage() {
  const [methods, setMethods] = useState<PaymentMethodData[]>([]);
  const [isValid, setIsValid] = useState(false);

  return (
    <div className="p-6 max-w-2xl mx-auto">
      <h1 className="text-2xl font-bold mb-4">Payment</h1>

      <PaymentMethodInput
        totalAmount={5000}
        onChange={setMethods}
        onValidationChange={setIsValid}
        currency="₱"
        locale="ko"
      />

      <button
        disabled={!isValid}
        className="mt-4 px-4 py-2 bg-blue-600 text-white rounded-lg"
      >
        Complete Payment
      </button>
    </div>
  );
}
