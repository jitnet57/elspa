#### 1. Analyst (비즈니스 분석가)
```
역할:
├─ 프로젝트 현황 분석
├─ 이해관계자 요구사항 수집
├─ 성공 지표 정의
└─ 최종 비즈니스 케이스 작성

비용 계산:
├─ 기간: 5월 (1개월)
├─ 시급: $500/일 (8시간 × $62.5/시간) 또는 $2,000/주
├─ 근무: 주 5일 × 4주 = 20일
├─ 총비용: $500/일 × 20일 = $10,000
└─ 실제: $8,000 (타임라인 조정, 기존 BMAD 분석 활용)

근거:
- 시장 표준: 비즈니스 분석가 연봉 $60K-80K → 월 $5K-6.7K
- 프로젝트 1개월 투입 기준
- 기존 분석 자료 활용으로 시간 단축
```

```
역할:
├─ PRD (Product Requirements Document) 작성
├─ User Stories 및 Use Cases 정의

├─ 기간: 2개월 (5월-6월)
├─ 월급: $2,000/주 × 4주 = $8,000/월
├─ 총비용: $8,000 × 2개월 = $16,000
│
└─ 연간 환산:
   ├─ 월급: $8,000
   ├─ 연봉: $96,000
   └─ 시장 표준: PM 연봉 $80K-120K

근거:
- 시니어 PM 연봉 기준: $80K-120K/년
- 이 프로젝트: 2개월 풀타임 투입
- 계산: ($100K/년) × (2개월/12개월) = $16,667 → 반올림 $16,000
```
