### 1. Google Sheets가 경쟁 우위다
```

✅ ElSpa: "Google Sheets 자동화"
   → 거부감 낮음, 마이그레이션 비용 0
   → 이미 알고 있는 도구 활용
```

### 2. 급여정산이 수익 엔진이다
```
문제: 월급 12시간 + 오류

ROI: 월 50K 투자 → 연 1.8M 절감

```
채널별 CAC:
├─ 커뮤니티: 300K (신뢰도 높음)
