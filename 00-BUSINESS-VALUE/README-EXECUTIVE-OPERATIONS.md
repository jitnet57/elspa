## 📅 THE WEEKLY RHYTHM

**Every week follows the same pattern:**

```
MONDAY    09:00 | Weekend metrics review + All-hands standup
TUESDAY   09:00 | Daily standup + Sprint review/planning (CTO)
WEDNESDAY 09:00 | Daily standup + P&L review (CFO)
THURSDAY  09:00 | Daily standup + 1:1 meetings with leaders
FRIDAY    14:00 | DECISION DAY (WBR + Go/No-Go decisions)
```

**That's it.** Same meetings, same time, every week.

## 🤔 FAQ

**Q: Do we really need to meet every day?**
A: The daily standup is only 15 min and keeps everyone aligned. Skip it and decisions slow down.

**Q: What if we miss a deadline?**
A: Document it, explain why, adjust the plan. The system tracks this.

**Q: Can we customize this for our business?**
A: Yes. This is a template. Adjust metrics/timing to fit your reality.

**Q: How do we know if it's working?**
A: Run a 90-day trial, measure the success metrics (faster decisions, better alignment), adjust.

**Q: What if the CEO is busy and misses Friday decision day?**
A: Reschedule to the next available slot, but don't skip. Decisions pile up if you don't have a rhythm.

## 🎯 CORE PHILOSOPHY

This system is built on **5 principles:**

1. **Rhythm** — Same meeting, same time, every week (predictability)
2. **Accountability** — Every metric has an owner, every decision has a deadline
3. **Data-driven** — Decisions backed by numbers, not gut feel
4. **Transparency** — All metrics public to leadership team (no surprises)
5. **Iteration** — Month 1: Get the rhythm. Month 2: Refine. Month 3: Optimize.

**The system is not perfect on day 1.** You'll adjust it based on experience. That's the point.
