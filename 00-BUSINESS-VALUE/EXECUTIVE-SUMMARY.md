## 2. 3가지 초기 마케팅 전략

### 전략 1: 로컬 커뮤니티 중심 (신뢰도 High, ROI 최고)

**Target:** 카톡 오픈채팅 + 인스타그램 해시태그

```
Q2: 100명 확보 (무료 베타)
Q3: 250명 (커뮤니티 50% 할인)
Q4: 400명 (유기 성장 + 추천)
```

**예상 CAC:** 300K (가장 낮음)  
**전환율:** 8-10%  
**Cost:** 월 500K (커뮤니티 활동 인력 + 카톡 유지비)

---

### 전략 2: 콘텐츠 + SEO (장기 ROI, 지속성 높음)

**Target:** 네이버 블로그, YouTube Case Studies

```
콘텐츠:
├─ "마사지샵 급여정산 자동화" (월 1K 검색)
├─ "테라피스트 스케줄 관리" (월 2K 검색)
├─ Case Study 영상 (YouTube)
└─ 주 2회 포스팅 × 6개월 = 48개

예상 도달: 50K+/월 (6개월 후)
전환율: 0.5-1% = 250-500명/월
```

**예상 CAC:** 200K (SEO는 초기 투자 높음, 장기 낮음)  
**Timeline:** 3-6개월 (SEO는 지연됨)  
**Cost:** 월 1M (콘텐츠 제작 + 편집)

---

### 전략 3: B2B 파트너십 (빠른 성장, 신뢰도 높음)

**Target:** 마사지샵 체인점, 회계 대행사, POS 솔루션

```
초기 전략:
├─ 체인점 직영업 (10개 체인 × 5개 지점 = 50명)
├─ 회계 대행사 5개 (각 50명 소개 = 250명)
├─ POS 솔루션 2개 (통합 & 수익 공유)
└─ 커미션: 20-30% 또는 수수료 공유

예상 도달: 300명 (첫 분기)
전환율: 20%
```

**예상 CAC:** 150K (가장 낮음, 파트너 수익 분담)  
**Timeline:** 즉시 (이미 관계 있음)  
**Cost:** 월 2M (B2B 영업팀 1명)

```
고객 LTV (36개월):
├─ Pro: 49K × 24개월 = 1.18M (전환 후 평균 보유기간 24개월 가정)
├─ Business: 199K × 36개월 = 7.16M

고객 CAC (획득 비용):
├─ 커뮤니티 경로: 300K
├─ 파트너 경로: 150K
├─ 웨비나/SEM: 500K

LTV:CAC Ratio = 1.18M : 300K = 3.9:1 (우수)
```

## 9. 성공의 열쇠 (Must-Have)

### 1. Google Sheets 중심성
- 마이그레이션 비용 최소화 = 사용자 획득 용이
- "새로운 앱 배우기" 거부감 최소화
- 기존 workflow와의 호환성 최고

### 2. 급여정산 자동화
- 마사지샵 경영자의 가장 큰 pain point
- ROI 명확 (월 50K → 연 1.8M 절감, 14일 payback)
- 구전 효과 높음 (직원과 경영자 모두 만족)

### 3. 로컬 우위
- 한국 법규 준수 (근로기준법, 세무 규정)
- 한국 결제 시스템 기본 통합
- 해외 경쟁사 3-6개월 앞서감

### 4. 커뮤니티 빠른 구축
- 초기 500명 = 업계 데이터 자산
- "마사지샵 벤치마크 리포트" 마케팅 자산
- 네트워크 효과 (추천 → 성장 가속)
