## 주요 성공 요인 (Critical Success Factors)

### 1. Google Sheets 중심성 ⭐⭐⭐⭐⭐
```
왜 중요한가:
- 마이그레이션 비용 0
- 학습곡선 0
- 기존 workflow 유지

실행:
- 모든 마케팅에 "Google Sheets"를 메시지에 포함
- "새로운 앱? 필요 없습니다"가 메인 카피
- 홈페이지 1번 이미지: Google Sheets 스크린샷
```

### 2. 급여정산 자동화 ⭐⭐⭐⭐⭐
```
왜 중요한가:
- 마사지샵 경영자의 가장 큰 pain point
- ROI 명확 (월 50K → 연 1.8M)
- Payback 14일 = 빠른 전환

실행:
- 첫 케이스 스터디: "월급날 전쟁 종료"
- 동영상: Before/After 10분 vs 10초
- 고객증언: "이제는 잠을 잘 수 있어요"
```

### 3. 빠른 커뮤니티 구축 ⭐⭐⭐⭐
```
왜 중요한가:
- 초기 고객 확보 (신뢰도 높음)
- 데이터 자산 축적
- 경쟁사 따라올 수 없는 moat

실행:
- 카톡 5개 커뮤니티 주 3회 활동
- "마사지샵 경영팁" 무료 콘텐츠 배포
- 월 1회 웹세미나 개최
- 추천 프로그램 (기존 → 신규 20% 할인)
```

### 4. 로컬 우위 강화 ⭐⭐⭐⭐
```
왜 중요한가:
- 해외 경쟁사 3-6개월 뒤쳐짐
- 한국 법규 변경에 빠른 대응
- 고객 신뢰도 (한글 지원, 한국 이해)

실행:
- 근로기준법 변경 → 즉시 자동 반영
- 최저임금 변경 → 시스템 자동 업데이트
- 한국 세무 규정 → 분기별 검토 및 반영
- 한국식 UI/UX 유지 (컨설팅 포함)
```

### 5. 재정 건전성 ⭐⭐⭐⭐
```
왜 중요한가:
- 12개월 활주로 (Seed 250M)
- 6개월 내 break-even 가능
- Series A 투자자 신뢰도

실행:
- Seed 투자 6월 말까지 완료
- CAC < 500K 유지
- LTV:CAC > 3:1 달성 (년중 모니터링)
- Monthly Burn Rate 월 20M 이내 유지
```

## 자주 묻는 질문

### Q: 정말 월 50K로 충분한가?
**A:** 네, 검증됨. 
- 고객 20명 인터뷰 → 80% "월 50K 가능"
- Early access 프로그램 → 30-40% 자발적 Pro 전환
- 급여정산 가치 >> 50K (연 1.8M 절감)

---

### Q: 경쟁사가 급여정산 추가하면?
**A:** 3-6개월 지연 가능.
- 한국 세무/근로법 복잡 (이해 + 구현에 시간)
- 우리는 이미 완성 + 운영 중
- 데이터 자산 축적 중 (벤치마크, AI)

---

### Q: 아시아 확장은 언제?
**A:** Y2 후반 (2027년 말).
- 한국 5,000명 달성 후 (Y3 목표)
- 필리핀, 태국, 싱가포르 순서
- 현지화: 1개국당 3-6개월

---

### Q: Break-even은 정말 6개월?
**A:** 현실적이지만 보수적 추정.
- 고정비: 월 24M
- 고객당 순이익: 70.5K
- Break-even: 344명
- Y1 말 500명 = 6개월 내 달성 가능

---

### Q: Series A는 언제?
**A:** Y1 말 (2026년 11월).
- 조건: ARR 120M + CAC 500K 이하 + Churn 5% 이하
- 목표: KRW 1B
