## 1. 비즈니스 현황 분석

### 1.1 현재 업무 프로세스 (AS-IS)

```
고객 문의              상담 처리                예약 관리              실행 & 정산
┌──────────┐    ┌──────────────────┐    ┌──────────┐    ┌──────────────┐
│ 채널    │    │ 담당자 수동       │    │ 구글시트  │    │ 수기 기록    │
├─────────┤    ├──────────────────┤    ├──────────┤    ├──────────────┤
│메신저   │───→│상담 기록 (미흡)  │───→│ 예약 기록│───→│ 수금 기록   │
│카톡     │    │ 누락 위험        │    │(누락주의) │    │ 정산 (수동) │
│전화     │    │시간 낭비          │    │          │    │ 룸/테라피스 │
│이메일   │    │                  │    │          │    │ 기록 미흡   │
└──────────┘    └──────────────────┘    └──────────┘    └──────────────┘
      │                                       │                 │
      └───────────────── 채널 분산, 정보 손실 ─────────────────┘
```

### 1.2 현재 시스템 구성
| 영역 | 도구 | 상태 | 문제점 |
|------|------|------|--------|
| **상담/예약** | 메신저/카톡 + 구글시트 | 분산 | 누락, 중복, 검색 어려움 |
| **스케줄 관리** | 구글시트(수동) | 미흡 | 룸/테라피스트 충돌 가능 |
| **결제/정산** | 구글시트(수기) | 수동 | 인적오류, 매일 수동 정산 |
| **직원관리** | 종이(?) | 없음 | 신상기록/경고/상벌 추적 불가 |
| **드라이버 배정** | 전화/메시지 | 분산 | 픽드랍 요청 시마다 수동 |
| **마케팅 채널** | 지정하지 않음 | 미흡 | 신규 플랫폼 대응 불가 |

### 1.3 주요 통증점 (Pain Points)

#### 1단계: 문의→상담 (채널)
- **문제**: 메신저/카톡 등 여러 채널로 들어오는 고객 상담이 산재
- **결과**: 상담 이력 누락, 응답 지연, 고객 불만족
- **원인**: 채널 통합 시스템 부재

#### 2단계: 상담→예약 (데이터 이관)
- **문제**: 구글시트로 수동 옮기다 보니 정보 누락
- **결과**: 예약 불일치, 고객 혼동, 스케줄 오류
- **원인**: 자동 연동 없음

#### 3단계: 예약→실행 (룸/테라피스트 배정)
- **문제**: 룸 가용성과 테라피스트 가용성을 한눈에 볼 수 없음
- **결과**: 중복 예약, 대기 시간 증가, 고객 경험 악화
- **원인**: 통합 스케줄 뷰 부재

#### 4단계: 실행→정산 (재무)
- **문제**: 고객별 계산을 구글시트에 수기로 기록 후 매일 수동 정산
- **결과**: 정산 오류, 시간 낭비, 감시 어려움
- **원인**: 자동 결제/정산 시스템 없음

#### 5단계: 운영관리
- **문제**: 직원 신상, 경고, 상벌 기록이 없음 / 픽드랍 요청 시마다 수동 스케줄
- **결과**: 인사관리 미흡, 드라이버 연동 오류
- **원인**: 통합 관리 시스템 부재

## 2. 개선 요구사항 분석

### 2.1 자동화 대상 프로세스

| # | 개선 영역 | 현재 상태 | 목표 상태 | 기대효과 |
|----|---------|---------|---------|---------|
| **1** | 채널상담→예약 이관 | 수동(누락주의) | 자동(누락방지) | 정보손실 ↓, 정확성 ↑ |
| **2** | 마케팅 플랫폼 자동화 | 지정안됨 | 플랫폼 감지→자동업그레이드 | 유지보수 자동화 ↓ |
| **3** | 야간/새벽 상담 | 수동(비용↑) | AI 자동상담 | 운영비 ↓, 고객만족 ↑ |
| **4** | 픽드랍→드라이버스케줄 | 수동전화 | 자동연동 | 오류 ↓, 응답시간 ↓ |
| **5** | 정산 자동화 | 수기(매일) | 자동(실시간) | 관리시간 ↓ 90%, 오류 ↓ |
| **6** | 룸/테라피스트 조율 | 수동확인 | 실시간 통합뷰 | 중복예약 ↓, UX ↑ |
| **7** | 직원관리 | 종이(?) | 디지털 기록 | 투명성 ↑, 감시 ↑ |
| **8** | 지출/수입 추적 | 수동기록 | 자동추적 | 감시 ↑, 오류 ↓ |

### 2.2 요구사항 우선순위 (MoSCoW)

#### MUST (1주차)
- ✅ 채널→예약 자동 이관 (누락방지)
- ✅ 구글시트 정산 자동화 (매일 수동 → 실시간 자동)
- ✅ 룸/테라피스트 시간대별 통합뷰 (스케줄 충돌 방지)

#### SHOULD (2-3주차)
- ✅ 야간 상담 AI 자동응답
- ✅ 픽드랍↔드라이버 자동연동
- ✅ 직원 신상/경고 기록 관리

#### COULD (4주차+)
- 마케팅 플랫폼 자동 감지/업그레이드
- 고급 분석 & 리포팅
