5. 커스텀 명령어 (10+개)
================================================================================

인증:
  - cy.login(email, password)       // 로그인
  - cy.loginWithToken(token)        // 토큰 기반 로그인
  - cy.logout()                     // 로그아웃

네비게이션:
  - cy.navigateTo(path)             // 페이지 이동

폼 작업:
  - cy.fillForm(formData)           // 다중 필드 입력
  - cy.selectDropdown(sel, value)   // 드롭다운 선택

테이블:
  - cy.findTableRow(text)           // 행 찾기
  - cy.getTableData()               // 데이터 추출

대기:
  - cy.waitForElement(selector)     // 요소 대기
  - cy.waitForAPI(alias)            // API 대기
  - cy.checkNotification(msg, type) // 알림 확인

파일:
  - cy.uploadFile(sel, filename)    // 파일 업로드

8. 시작하기
================================================================================

로컬 테스트 실행:
  1. cd frontend
  2. npm run cypress:open
  3. 테스트 파일 선택
  4. Run specs 클릭

자동 테스트 실행:
  1. npm run cypress:run (모든 테스트)
  2. npm run cypress:report (리포트 생성)

특정 브라우저 테스트:
  1. npm run cypress:run:chrome
  2. npm run cypress:run:firefox
  3. npm run cypress:run:edge

디버그:
  1. npm run cypress:debug
  2. Dev Tools 사용하여 디버깅

9. Mock API 설정
================================================================================

cypress/support/e2e.ts에 다음 Mock 함수들이 구현됨:

  - setupMockAuth()        // 로그인/인증 API
