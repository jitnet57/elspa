================================================================================
🔌 API 엔드포인트 (7개)
================================================================================

그룹 1: 결제 방법 관리 (4개)
────────────────────────────────────────────────────────────────────────────
  1. POST   /api/bookings/{id}/payment-methods
     - 예약에 결제 방법 추가
     - 지원: 은행송금, GCash, 현금, 수표, 카드, 수기 기록

  2. PATCH  /api/bookings/{id}/sss-option
     - SSS (Social Security System) 정산 옵션 업데이트
     - 필리핀 사회보장시스템 지원

  3. PATCH  /api/bookings/{id}/payment-from
     - 결제 출처 업데이트
     - 고객 직접, 기업 외상, 바우처, 멤버십, 프로모션

  4. GET    /api/bookings/{id}/payment-info
     - 예약의 모든 결제 정보 조회
     - 통합 응답

그룹 2: 정산 관리 (3개)
────────────────────────────────────────────────────────────────────────────
  5. GET    /api/settlements/pending
     - 정산 대기 목록 조회
     - 페이지네이션 지원
     - 필터링 지원 (company_id, status)

  6. GET    /api/settlements/{id}
     - 정산 상세 조회
     - 거래 내역 포함

  7. PATCH  /api/settlements/{id}/mark-settled
     - 정산 완료 처리
     - 관리자 전용
     - 지급 정보 기록


================================================================================
📊 데이터 구조
================================================================================

결제 방법 종류 (6가지)
  - bank_transfer: 은행 송금
  - gcash: GCash (필리핀 전자지갑)
  - cash: 현금
  - check: 수표
  - card: 카드
  - manual: 수기 기록

SSS 상태 (4가지)
  - not_applicable: 해당 없음
  - prepaid: 선지급 (회사 사전 지급)
  - gov_invoice: 정부 인보이스 기반
  - full_recovery: 전액 회수

결제 출처 (5가지)
  - customer: 고객 직접 (회수율 100%)
  - company_credit: 기업 외상 (회수율 변동)
  - voucher: 바우처 (회수율 0%)
  - membership: 멤버십 (회수율 100%)
  - promo: 프로모션 (회수율 0%)

정산 상태 (6가지)
  - draft: 초안
  - pending: 대기 중
  - approved: 승인됨
  - settled: 정산 완료
  - confirmed: 확정됨
  - rejected: 거부됨

🎯 사용 예시
================================================================================

시나리오 1: 고객 직접 결제
─────────────────────────────────────────────────────────────────────────────
  1. POST /api/bookings/12345/payment-methods
     → 은행송금 정보 추가
  
  2. PATCH /api/bookings/12345/payment-from
     → payment_from: "customer" 설정
  
  3. GET /api/settlements/pending
     → 정산 대기 목록 조회
  
  4. PATCH /api/settlements/1/mark-settled
     → 정산 완료 처리

시나리오 2: 기업 외상
─────────────────────────────────────────────────────────────────────────────
  1. PATCH /api/bookings/12345/payment-from
     → payment_from: "company_credit"
     → company_credit_id: 567
  
  2. PATCH /api/bookings/12345/sss-option
     → sss_status: "prepaid"
     → sss_contribution_percent: 12.5

  - HTTP: Axios

  - 상태 관리: Zustand
