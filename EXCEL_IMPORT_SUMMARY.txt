요청: Create excel_import_router.py - API endpoints (FastAPI/Hono)

1. GET /api/import/tables
   └─ Return: list of supported tables with fields

2. POST /api/import/parse-excel
   └─ Input: file + tableName
   └─ Return: headers, sampleData, totalRows, suggestedMapping

3. POST /api/import/validate-mapping
   └─ Input: file + mapping + tableName
   └─ Return: isValid, warnings, errors, previewData

4. POST /api/import/execute (streaming)
   └─ Input: file + mapping + tableName
   └─ Return: ImportResult with success/failed counts

Include: File validation, auth check, error handling
Return: Complete router with all endpoints + schemas

【API 엔드포인트 - 4개】

✅ GET /api/import/tables
   • 지원 테이블 목록 및 필드 정보 반환
   • 인증 필수 (JWT)
   • 응답: {tables: [...], total_count: 5}

✅ POST /api/import/parse-excel
   • 엑셀 파일 파싱 및 자동 매핑 제안
   • 매개변수: file, table_name
   • 응답: {headers, sample_data, total_rows, suggested_mapping}

✅ POST /api/import/validate-mapping
   • 매핑 검증 및 데이터 미리보기
   • 매개변수: file, table_name, mapping
   • 응답: {is_valid, errors, warnings, preview_data, total_rows}

✅ POST /api/import/execute (SSE 스트리밍)
   • 실제 데이터 저장
   • 매개변수: file, table_name, mapping, skip_errors
   • 응답: Server-Sent Events (progress + complete)
