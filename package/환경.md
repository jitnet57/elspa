## 🖥️ 로컬 개발 환경

### 요구사항
- **Node.js** 18+ (프론트엔드)
- **Python** 3.10+ (백엔드)
- **Git** (버전 관리)
- **PostgreSQL** CLI (선택적, Supabase 연결용)

### 프론트엔드 개발

```bash
# 의존성 설치
cd frontend
npm install

# 개발 서버 시작
npm run dev
# http://localhost:3000 접속

# 프로덕션 빌드
npm run build

# 프로덕션 실행
npm start

# 타입 검사
npm run type-check
```

### 백엔드 개발

```bash
# 가상 환경 생성
python -m venv venv
source venv/bin/activate  # Mac/Linux
# or
venv\Scripts\activate  # Windows

# 의존성 설치
pip install -r requirements.txt

# 개발 서버 시작
python main.py
# http://localhost:8000/docs (Swagger UI)

# 데이터베이스 마이그레이션
# (Alembic 사용 시)
alembic upgrade head
```

## 🔄 개발 워크플로우

### 작업 흐름
```
1️⃣ 기능 개발 (로컬)
   ├─ 백엔드: app/routers/*.py 작성
   └─ 프론트엔드: frontend/src/app/*.tsx 작성

2️⃣ 테스트 (로컬)
   ├─ npm run dev (프론트엔드)
   └─ python main.py (백엔드)

3️⃣ 빌드 & 검증
   ├─ npm run build (프론트엔드)
   └─ 타입 에러 없는지 확인

4️⃣ Git 커밋
   ├─ git add .
   └─ git commit -m "이모지 메시지"

5️⃣ 푸시 & 자동 배포
   └─ git push origin main
      → Cloudflare/Railway 자동 배포 시작

6️⃣ 히스토리 기록
   └─ history-workflow-book.md에 Order 추가
```
