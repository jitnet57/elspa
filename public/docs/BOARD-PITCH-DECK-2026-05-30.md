## 📉 SLIDE 2: 위기 상황 분석 (1/2)

### **경제 환경: "Perfect Storm" 시나리오**

**주요 지표**:
- 🔴 **고금리 시대**: 기준금리 3.5% → 5.5% (5개월간 +200bp)
- 🔴 **고물가**: 연간 인플레이션 4.2% (작년 2.1% 대비 2배 증가)
- 🔴 **고환율**: USD/KRW 1,350 → 1,420 (고착)
- 🔴 **소비 위축**: 신용카드 사용액 전년 대비 -18.3%

**마사지/스파 시장 영향**:
```
2025년 시장규모     2026년 예상      2027년 전망
   ₩ 4.2조         ₩ 3.8조 (-9%)    ₩ 3.5조 (-20%)
   
고객군별 영향도:
- 고소득층 (20%) : -5% (여유 유지)
- 중산층 (60%)   : -18% (가계부채 > 50%)
- 저소득층 (20%) : -35% (사치재 제외)
```

**Speaker Notes (45초)**:
- 현재 경제 상황은 단순한 경기 침체가 아닙니다. 고금리, 고물가, 고환율이 동시에 진행되고 있습니다.
- 특히 마사지/스파 산업은 "사치재"로 분류되어 소비 위축의 최전선에 있습니다.
- 저희의 기존 고객들은 이미 서비스 빈도를 줄이고 있으며, 신규 고객 획득 비용이 크게 증가했습니다.
- 이것이 우리가 3개의 신규 채널을 동시에 개발해야 하는 이유입니다.

## 🔵 SLIDE 4: Track A - B2B 파트너 통합

### **"API 연동을 통한 기존 시스템 강화"**

**목표**: 어썸팀/타임온 같은 HR시스템과 파트너십 → 월 ₩50M+ 추가 수익

**Track A 비즈니스 모델**:

```
┌─────────────────┐
│  HR System      │ (어썸팀, 타임온, 더존 등)
│  (기존 고객)     │
└────────┬────────┘
         │ API 호출
         ▼
┌─────────────────┐
│  ElSpa Engine   │ ⚡ 급여계산 API
│  (우리 기술)     │   Rate Limit: 1,000 req/min
└────────┬────────┘
         │ JSON Response
         ▼
┌─────────────────┐
│  급여명세서     │
│  (자동 생성)     │ 월 건당 ₩50K-150K 수익
└─────────────────┘
```

**수익 시뮬레이션**:
- 어썸팀 (고객 5,000명): 월 ₩25M
- 타임온 (고객 3,000명): 월 ₩15M
- 더존 (고객 2,000명): 월 ₩10M
- **합계**: 월 ₩50M (연 ₩600M)

**Week 1 Deliverable**:
- ✅ POC 계약서 1곳 체결 (어썸팀 or 타임온)
- ✅ 기술 스펙 문서 작성 (3페이지)
- ✅ 파일럿 API 테스트 완료

**Speaker Notes (60초)**:
- Track A는 가장 실행 가능한 전략입니다.
- 우리는 이미 40개 이상의 급여계산 API 엔드포인트를 완성했고, 철저히 테스트했습니다.
- 기존 HR시스템(어썸팀, 타임온)은 급여계산 기능에 투자하지 않고 있기 때문에, 우리 API를 추가하면 즉시 가치를 제공할 수 있습니다.
- 파트너는 "클릭 몇 번으로 고객에게 새로운 기능 제공" → 고객 만족도 증가 → 우리는 거래당 수수료 수취.
- Week 1 목표는 POC 계약 1건입니다. 어썸팀 또는 타임온 중 한 곳에서 "테스트해보자"는 합의를 얻는 것입니다.

## 🟢 SLIDE 5: Track B - 프리랜서/요양원 플랫폼

### **"B2C 간병인 중개 플랫폼 확장"**

**목표**: 요양원/병원과 파트너십 → 월 ₩80M+ 추가 수익 (6개월 후)

**Track B 비즈니스 모델**:

```
┌──────────────┐         ┌──────────────┐
│   요양원     │◄────────│  ElSpa SaaS  │
│ (간병인 관리) │ 월 ₩5M  │  (우리 플랫폼)│
│   (5곳)      │         │              │
└──────────────┘         └──────────────┘
     
┌──────────────┐         ┌──────────────┐
│   병원      │◄────────│  간병인 DB   │

│   (3곳)      │         │              │
└──────────────┘         └──────────────┘

연간 예상 수익: ₩80M-120M (Month 6부터)
```

**요양원의 Pain Point**:
- 간병인 관리: 엑셀 + 전화 (24시간 대응 불가)
- 일정 배치: 수기 배정 (빈번한 실수)
- 급여 정산: 수기 계산 (정확도 낮음)

**우리 제공 가치**:
- ✅ SaaS 플랫폼: 간병인 관리 자동화
- ✅ 스케줄링: AI 기반 자동 배치
- ✅ 급여 통합: Track A API 직접 연동

**Week 1 Deliverable**:
- ✅ 파일럿 요양원 1곳 선정 (서울/경기)
- ✅ SaaS 모듈 프로토타입 완성 (UI 데모)
- ✅ 파일럿 계약서 체결

**Speaker Notes (60초)**:
- Track B는 가장 빠르게 성장할 수 있는 채널입니다.
- 한국에는 약 3,000개의 요양원이 있습니다. 대부분 아직도 엑셀로 간병인을 관리합니다.
- 우리가 제공하는 시스템은 "간병인을 3명 줄일 수 있다"는 가치를 만듭니다.
- 요양원당 월 ₩5M-8M의 수수료를 받을 수 있습니다.
- Week 1 목표는 파일럿 요양원 1곳을 선정하고 계약서를 쓰는 것입니다.
- 3-6개월 안에 10곳 이상으로 확대할 계획입니다.

## 🔴 SLIDE 6: Track C - 고객 유지 및 NPS 최적화

### **"기존 고객 이탈률 37% → 15% 감소"**

**목표**: NPS 기반 분석 → 월 ₩30M 매출 방어 (손실 최소화)

**Track C의 핵심 통계**:

```
현재 상황 (2026년 5월):
┌─────────────────────────────────┐
│ 월 활성 고객: 2,500명            │
│ 월평균 객단가: ₩200K (4회 방문)  │
│ 월 매출: ₩500M                   │
│                                  │
│ 이탈률: 37% (월 925명 이탈)      │
│ 이탈 원인:                        │
│  ├─ 경제 사정 (70%)              │
│  ├─ 경험 불만족 (20%)           │
│  └─ 경쟁사 이동 (10%)            │
│                                  │
│ 현재 손실: 월 ₩185M             │
└─────────────────────────────────┘

3개월 후 (Track C 적용):
┌─────────────────────────────────┐
│ 이탈률: 15% (목표)               │
│ 유지 고객: 2,125명 (52% 개선)   │
│ 매출 손실: 월 ₩85M (-54%)       │
│                                  │
│ 순이익: 월 ₩100M 추가            │
│ (3개월 누적: ₩300M)             │
└─────────────────────────────────┘
```

**Track C 전술**:
1. **NPS 기반 세그먼트**
   - 고위험군 (NPS < 0): 즉시 콜드 콜 → 할인/프로모션
   - 중립층 (NPS 0-30): AI 추천 → 맞춤 패키지
   - 충성층 (NPS > 70): VIP 로열티 → 재방문율 +30%

2. **AI 이탈 예측**
   - 방문 간격 증가 → 이탈 확률 70%
   - 예약 취소 증가 → 이탈 확률 60%
   - 리뷰 감정 부정적 → 이탈 확률 50%

3. **개입 액션**
   - 자동 알림 (Slack/이메일/카톡)
   - 한정 오퍼 (1주일 유효)
   - 콜센터 우선순위 배치

**Week 1 Deliverable**:
- ✅ 기존 고객 NPS 데이터 수집 (10곳 이상)
- ✅ AI 이탈 예측 모델 구축 (정확도 85%+)
- ✅ 자동 개입 워크플로우 설계

**Speaker Notes (60초)**:
- Track C는 "수비"입니다. 공격이 아니라 방어입니다.
- 현재 우리는 매달 ₩185M을 잃고 있습니다. 이탈률 37%는 정상이 아닙니다.
- 같은 고객을 다시 획득하는 데 드는 비용은 유지하는 데 드는 비용의 5배입니다.
- Track C의 전략은 간단합니다: 떠나가려는 고객을 데이터로 찾아내고, 올바른 메시지를 올바른 시점에 전달합니다.
- NPS와 AI를 결합하면 개인화된 개입이 가능합니다.
- Week 1 목표는 10곳 이상의 기존 고객에게서 NPS 데이터를 수집하고, AI 모델을 테스트하는 것입니다.
