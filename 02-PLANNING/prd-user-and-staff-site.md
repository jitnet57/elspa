## Part 1: User Site (고객용 예약 앱)

### 1.1 개요

```
사용자: 고객 (예약자)
목적: 예약, 추적, 이력, 리뷰
복잡도: 낮음 (필수 기능만)
사이트: app.elspa.com
```

### 1.2 핵심 기능 (4가지)

| # | 기능 | 설명 |
|---|------|------|
| 1 | **로그인/가입** | 이메일, 소셜 로그인 |
| 2 | **예약하기** | 실시간 예약, 채널 통합 (메신저/카톡/앱) |
| 3 | **예약 추적** | 진행상황, 픽드랍 추적, 매장 오는 길 |
| 4 | **이력 & 리뷰** | 지난 예약, 후기 작성, 저장된 테라피스트 |

### 1.4 User Site 기술 요구사항

```
주요 API:
GET /api/user/profile              # 내 정보
POST /api/bookings                 # 예약 생성
GET /api/bookings                  # 내 예약 목록
GET /api/bookings/:id              # 예약 상세
PUT /api/bookings/:id              # 수정
DELETE /api/bookings/:id           # 취소
GET /api/availability              # 가능 시간대
POST /api/reviews                  # 리뷰 작성
GET /api/pickups/:id               # 픽드랍 추적

외부 통합:
- Google Maps (길찾기)
- 메신저/카톡 (예약 확인 메시지)
- Twilio SMS (픽드랍 알림)
```

## Part 2: Staff Site (테라피스트 & 드라이버)

### 2.1 개요

```
사용자: 테라피스트 + 드라이버
목적: 스케줄 확인, 픽드랍, 평가
복잡도: 중간 (모바일 중심)
플랫폼: React Native (iOS/Android)
사이트: staff.elspa.com (또는 모바일 앱)
```

### 2.2 핵심 기능 (테라피스트)

| # | 기능 | 설명 |
|---|------|------|
| 1 | **내 스케줄** | 오늘/주간 예약 확인 |
| 2 | **예약 상세** | 고객정보, 특별요청, 채팅 |
| 3 | **가용성 관리** | 휴식, OFF, 구글캘린더 동기 |
| 4 | **성과 조회** | 월 매출, 평점, 피드백 |

### 2.5 Staff Site 기술 요구사항

```
주요 API:
GET /api/staff/schedule         # 오늘 스케줄
POST /api/bookings/:id/start    # 서비스 시작
POST /api/bookings/:id/complete # 서비스 완료
GET /api/staff/performance      # 성과 조회
GET /api/staff/pickups          # 픽드랍 리스트
POST /api/pickups/:id/accept    # 픽드랍 수락
GET /api/pickups/:id/location   # 실시간 위치

WebSocket:
socket.on('pickup:new')         # 새 픽드랍 요청
socket.on('schedule:updated')   # 스케줄 변경

외부 통합:
- Google Maps (네비게이션)
- Google Calendar (개인 일정)
- Firebase (푸시 알림)
```
