# 마사지/스파 통합 플랫폼 - UX 스펙
**Phase 2: UX/UI Design Specification | Date: 2026-05-05**

---

## 1. 디자인 원칙

### 1.1 핵심 원칙
- **통합성**: 모든 채널의 정보가 한 대시보드에 통합
- **실시간성**: 예약, 스케줄, 정산이 실시간 업데이트
- **간결성**: 복잡한 로직은 백그라운드에서 자동 처리
- **접근성**: 모든 사용자(Owner, Manager, Therapist, Receptionist)가 쉽게 사용

### 1.2 사용자별 진입점

```
┌─────────────────────────────────────────────┐
│       ElSpa Manager - 로그인                  │
├─────────────────────────────────────────────┤
│                                             │
│  [사용자명] [비밀번호]                        │
│  [로그인]                                    │
│                                             │
│  또는 소셜 로그인 (Google, Kakao)            │
│                                             │
└─────────────────────────────────────────────┘
        ↓
┌───────────────────────────────────────────────┐
│ 역할별 메인 대시보드                           │
├───────────────────────────────────────────────┤
│                                               │
│ 👔 Owner         📊 Manager       👨 Therapist│
│ [리포팅]  →      [스케줄]    →    [예약확인]   │
│                                               │
│ 📞 Receptionist  🚗 Driver                     │
│ [상담/예약] →    [픽드랍]                      │
│                                               │
└───────────────────────────────────────────────┘
```

## 3. 사용자 흐름 (User Flows)

### 3.1 Flow 1: 고객 상담 → 예약 생성

```
고객 (메신저/카톡)     
    ↓
[상담 메시지 전송]
"내일 스웨디시 60분 가능한가요?"
    ↓
[AI 자동상담 또는 담당자 응답]
    ├─ 시간대 확인
    ├─ 테라피스트 가용성 확인
    ├─ 룸 가용성 확인
    └─ 고객에게 옵션 제시
    ↓
[고객 선택]
"내일 14:00 김테라/룸A로!"
    ↓
[자동 예약 생성 + 확인요청]
원채널로 "예약 확정 되었습니다"
    ↓
[Receptionist 대시보드에 반영]
    ↓
[예약 당일]
관리자/테라피스트 앱에 알림
고객은 원채널로 "30분 뒤 시작예정" 알림
```

---

### 3.2 Flow 2: 야간 상담 (새벽 2시)

```
고객 (새벽 2시, 카톡)
"내일 오후에 가고 싶은데 예약 가능?"
    ↓
[AI 자동상담 즉시 응답]
"안녕하세요! 다음 서비스 중 어떤 것을 원하세요?
 1. 스웨디시
 2. 핫스톤
 3. 타이마사지
 (선택: 1번, 또는 원하는 시간 입력)"
    ↓
[고객 응답]
"스웨디시 60분, 내일 15:00"
    ↓
[AI 확인]
"15:00 스웨디시 60분 맞나요? [예] [아니오]"
    ↓
[AI 예약 생성]
"예약이 생성되었습니다!
 확인: 내일 15:00, 스웨디시 60분
 담당자가 아침에 확인할게요"
    ↓
[아침 9시, Receptionist가 AI 예약 검토]
    ├─ 테라피스트 가용성 재확인
    ├─ 룸 가용성 재확인
    └─ [승인] 또는 [거절+대안제시]
    ↓
[고객에게 최종 확인]
원채널로 "예약 확정되었습니다"
```

---

### 3.3 Flow 3: 드라이버 픽드랍 배정

```
고객 (예약 당일, 메신저)
"픽드랍 필요한데요"
    ↓
[시스템 자동 처리]
1. 픽업 주소 자동 인식
2. 도착지 (ElSpa) 자동 설정
3. 현재 드라이버 위치 조회
4. 도착예상시간 계산
5. 최적 드라이버 배정
    ↓
[드라이버 앱 알림]
"새 픽드랍 요청!
 👤 김××님
 📍 강남역 3번출구
 🏠 ElSpa (압구정로 150)
 ⏱️ 예상도착: 7분"
    ↓
[드라이버 선택]
[수락] → 네비게이션 자동 시작
    ↓
[고객에게 알림]
원채널로 "드라이버 배정되었습니다!
 현재 위치: 강남로
 예상 도착: 7분"
    ↓
[실시간 추적]
고객이 원채널 또는 앱에서 드라이버 위치 추적
    ↓
[완료]
"드라이버가 도착했습니다!"
시스템에 완료 기록
```

## 7. 검증 & 에러처리

### 7.1 폼 검증

```
예약 폼:
- 고객명: 필수, 2자 이상
- 전화번호: 필수, 010-xxxx-xxxx 형식
- 서비스: 필수, 드롭다운
- 시간: 필수, 가용 시간대만 선택 가능
- 테라피스트: 선택, 가용 여부에 따라 자동 필터링

실시간 검증 + 제출 시 최종 검증
오류 시 해당 필드 강조 + 에러메시지
```
