## 1. 개요

### 1.1 Admin Site 정의

```
사용자: 오너, 매니저
목적: 전체 비즈니스 운영 & 모니터링
범위: 예약, 직원, 정산, 고객, 분석
복잡도: 최상 (모든 기능)
```

### 1.2 핵심 기능 (6가지)

| # | 기능 | 설명 |
|---|------|------|
| 1 | **대시보드** | 실시간 매출, 예약 현황, 경고 알림 |
| 2 | **채널 통합** | 메신저/카톡/전화 상담함 (AI 자동상담 포함) |
| 3 | **스케줄 관리** | 룸/테라피스트 통합 뷰, 충돌 방지 |
| 4 | **정산** | 자동 정산, 거래 기록, 비용 관리 |
| 5 | **직원관리** | 신상, 기록(경고/상벌), 성과 추적 |
| 6 | **분석 & 리포트** | 매출/추세, 고객만족도, KPI |

## 3. 기술 요구사항

### 3.1 API Endpoints (Admin)

```
# 대시보드
GET /api/admin/dashboard           # 실시간 수치
GET /api/admin/dashboard/charts    # 차트 데이터

# 상담함 (통합)
GET /api/admin/chats               # 상담 목록
GET /api/admin/chats/:id           # 상담 상세
POST /api/admin/chats/:id/reply    # 답장 발송
POST /api/admin/chats/:id/booking  # AI 예약 승인

# 스케줄
GET /api/admin/schedule            # 통합 스케줄
PUT /api/admin/schedule/bookings/:id  # 재스케줄링

# 정산
GET /api/admin/finance/transactions  # 거래 조회
GET /api/admin/finance/settlement    # 정산 조회
POST /api/admin/finance/settlement   # 수동 정산

# 직원
GET /api/admin/staff               # 직원 목록
GET /api/admin/staff/:id           # 직원 상세
PUT /api/admin/staff/:id           # 정보 수정
POST /api/admin/staff/:id/records  # 기록 추가

# 보고서
GET /api/admin/reports/summary     # 요약 보고서
GET /api/admin/reports/detailed    # 상세 보고서
```

### 3.2 외부 통합

| 서비스 | 용도 | API |
|--------|------|-----|
| **ElevenLabs** | 음성→텍스트 | REST |
| **Caldotcom** | 스케줄 동기화 | Webhook + REST |
| **Google Calendar** | 테라피스트 일정 | OAuth 2.0 |
| **Google Sheets** | 정산 기록 | API v4 |
| **Google Maps** | 드라이버 위치 | Distance Matrix |

### 3.3 실시간 기능

```
WebSocket Events (Admin이 받는 알림):

   socket.on('chat:new', (data) => {

   })

   socket.on('booking:ai-pending', (data) => {
     // 관리자 승인 필요
   })

   socket.on('schedule:updated', (data) => {
     // 예약 생성/수정/취소
   })

   socket.on('alert:warning', (data) => {
     // 미수금, OFF신청, 충돌 등
   })
```
