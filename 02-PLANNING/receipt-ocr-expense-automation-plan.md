## 1. 개요

### 1.1 요구사항 정리

```
기능: 영수증 폴더에 스캔해서 넣으면
      자동 분류 및 계산해서 엑셀시트로 만들어지는 기능

구체적 요구사항:
1️⃣  영수증 스캔 & 업로드
    └─ 폴더에 드래그 & 드롭 (또는 카메라 촬영)

2️⃣  자동 인식 & OCR
    └─ Google Vision API (텍스트 추출)
    └─ AI 분석 (가게명, 금액, 날짜, 항목)

3️⃣  자동 분류
    └─ 카테고리별 분류 (용품, 유지비, 인건비 등)
    └─ AI 기반 분류 (중복 제거)

4️⃣  금액 계산
    └─ 합계 자동 계산
    └─ 카테고리별 소계
    └─ 월간/분기별 통계

5️⃣  Excel 자동 생성
    └─ 엑셀 파일 자동 생성
    └─ Google Sheets 자동 기록
    └─ 다운로드 가능

목표:
✅ 수동 입력 0% → 100% 자동화
✅ 비용 추적 시간: 90% 감소
✅ 오류율: 최소화 (OCR + 검증)
```

### 1.2 비즈니스 임팩트

```
현재 상황:
- 영수증 수동 분류 & 입력 (매일 30분)
- 오류 가능성 높음
- 월간 정산 시 재확인 필요

개선 후:
- 영수증 스캔만 (5초)
- 자동 분류 & 계산 (1초)
- 100% 정확도 (AI 검증)

효과:
├─ 시간: 30분/일 → 2분/일 (93% 감소)
├─ 비용: 월간 오류 수정 비용 0
├─ 효율: 실시간 비용 현황 파악
└─ 정산: 자동화 (월간 정산 1일 → 1시간)
```

### 2.2 Google Vision API (OCR)

```
프로세스:

업로드된 이미지
  ↓
Google Vision API
  ├─ TEXT_DETECTION (텍스트 추출)
  ├─ DOCUMENT_TEXT_DETECTION (문서 형식)
  └─ 좌표 & 신뢰도 반환
  ↓
후처리 (Claude AI)
  ├─ 텍스트 정규화
  ├─ 필드 추출 (가게, 금액, 날짜)
  ├─ 레이아웃 분석
  └─ 신뢰도 점수 계산
  ↓
검증 (사용자)
  ├─ 낮은 신뢰도 (<80%) → 수동 검증
  └─ 높은 신뢰도 (>95%) → 자동 승인

추출 항목:
├─ 가게명/거래처
├─ 날짜 (YYYY-MM-DD)
├─ 시간 (HH:MM)
├─ 항목 (여러 개)
│  ├─ 항목명
│  ├─ 수량
│  ├─ 단가
│  └─ 소계
├─ 세금 (VAT)
├─ 총액
└─ 결제 수단 (카드, 현금 등)
```

## 3. 자동 분류 & 인식

### 3.1 카테고리 분류 (AI 기반)

```
분류 체계:

1. 비용 카테고리
   ├─ 물품/용품 (상품 구매)
   │  └─ 마사지 오일, 수건, 탈취제 등
   ├─ 유지비 (시설 관리)
   │  └─ 청소용품, 세제, 향초 등
   ├─ 식비 (직원 식사)
   │  └─ 카페, 편의점, 음식점
   ├─ 교통비 (차량/픽드랍)
   │  └─ 주유비, 택시, 주차료
   ├─ 통신비 (전화, 인터넷)
   │  └─ 통신사 요금
   ├─ 광고/마케팅
   │  └─ 온라인 광고, 전단지
   ├─ 교육/교습
   │  └─ 직원 교육 비용
   ├─ 기타
   │  └─ 분류 불가 항목
   └─ 일반 (수동 확인 필요)

분류 로직 (Claude AI):

Prompt 생성:
"
다음 영수증 정보를 분석하고 
가장 적절한 비용 카테고리를 선택하세요.

가게명: 스타벅스 강남점
항목: 아메리카노, 바닐라 라떼, 샌드위치
금액: 20,000₩

카테고리 선택:
1. 물품/용품
2. 유지비
3. 식비 ← 선택됨 (신뢰도 99%)
4. 교통비
5. 통신비
6. 광고/마케팅
7. 교육
8. 기타

이유: 직원 또는 손님 대접용 음식 구매로 판단됨
신뢰도: 99%
"

결과:
{
  "category": "식비",
  "confidence": 0.99,
  "reasoning": "직원 또는 손님 대접용 음식 구매"
}
```

## 4. 금액 계산 & 정산

### 4.1 자동 계산 로직

```
입력:
├─ 영수증 1: 20,000₩ (식비)
├─ 영수증 2: 15,000₩ (물품)
├─ 영수증 3: 45,000₩ (유지비)
└─ 영수증 4: 10,000₩ (교통비)

자동 계산:

전체 합계:
└─ 총액 = 20,000 + 15,000 + 45,000 + 10,000 = 90,000₩

카테고리별:
├─ 식비: 20,000₩ (22.2%)
├─ 물품: 15,000₩ (16.7%)
├─ 유지비: 45,000₩ (50.0%)
└─ 교통비: 10,000₩ (11.1%)

기간별:
├─ 일일: 2026-05-05 = 90,000₩
├─ 주간: Week 19 = 350,000₩ (5일 기준)
├─ 월간: 2026-05 = 1,400,000₩ (예상)
└─ 누적: 2026-01-01 ~ = 5,200,000₩

추이:
└─ 저달 대비: -8% (예산 내)
└─ 목표 대비: +5% (약간 초과)
```

### 7.2 데이터베이스 테이블

```sql
CREATE TABLE receipts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- 파일 정보
  original_file_url VARCHAR(500) NOT NULL,
  file_name VARCHAR(200),
  file_size INTEGER,
  file_type VARCHAR(10), -- 'jpg', 'png', 'pdf'
  
  -- OCR & 추출
  ocr_text TEXT,
  extraction_confidence DECIMAL(3,2),
  
  -- 추출된 데이터
  store_name VARCHAR(200),
  store_category VARCHAR(100),
  transaction_date DATE,
  transaction_time TIME NULL,
  items JSONB, -- [{name, quantity, price, subtotal}, ...]
  total_amount INTEGER,
  tax_amount INTEGER DEFAULT 0,
  payment_method VARCHAR(50),
  
  -- 분류
  expense_category VARCHAR(50),
  category_confidence DECIMAL(3,2),
  
  -- 상태
  status ENUM('pending', 'processing', 'pending_classification', 
              'pending_review', 'approved', 'rejected', 'manual') DEFAULT 'pending',
  
  -- 검증
  verified_by UUID NULL,
  verified_at TIMESTAMP NULL,
  verification_notes TEXT,
  
  -- 중복
  duplicate_of UUID NULL,
  is_duplicate BOOLEAN DEFAULT false,
  
  -- 메타
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (verified_by) REFERENCES admins(id),
  INDEX idx_status (status),
  INDEX idx_transaction_date (transaction_date),
  INDEX idx_expense_category (expense_category)
);

CREATE TABLE expenses (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  receipt_id UUID NOT NULL,
  
  -- 비용 정보
  amount INTEGER NOT NULL,
  category VARCHAR(50) NOT NULL,
  date DATE NOT NULL,
  
  -- 설명
  description VARCHAR(500),
  notes TEXT,
  
  -- 첨부
  receipt_image_url VARCHAR(500),
  
  -- 상태
  status ENUM('pending', 'approved', 'rejected') DEFAULT 'approved',
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (receipt_id) REFERENCES receipts(id),
  INDEX idx_date (date),
  INDEX idx_category (category)
);

CREATE TABLE expense_summaries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  
  -- 기간
  summary_date DATE,
  summary_type ENUM('daily', 'weekly', 'monthly', 'yearly'),
  
  -- 합계
  total_amount INTEGER,
  category_breakdown JSONB, -- {category: amount, ...}
  
  -- 비교
  previous_period_amount INTEGER NULL,
  budget_amount INTEGER NULL,
  variance DECIMAL(5,2), -- % 차이
  
  -- 생성
  generated_at TIMESTAMP,
  
  INDEX idx_date_type (summary_date, summary_type)
);
```
