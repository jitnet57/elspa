## Part 1: 마케팅 분석 & 리포팅

### 1.1 개요

```
목적: 일레븐랩스(음성 상담) + 칼닷컴(예약) 데이터를 분석하여
      마케팅 의사결정을 지원하는 통계 리포트 제공

데이터 소스:
├─ ElevenLabs: 음성 상담 기록, 통화 시간, 성공률, 감정 분석
├─ Caldotcom: 예약 데이터, 고객, 서비스, 가격
├─ 내부 DB: 거래, 고객만족도, 직원성과
└─ Google Analytics (v2.0+): 웹사이트 방문

보고 주기:
- 일일 (매일 아침 9:00)
- 주간 (매주 월요일)
- 월간 (매월 1일)
- 분기별 (1/4, 4/1, 7/1, 10/1)
- 연간 (1/1)
```

## Part 2: 데이터베이스 자동 백업 & 복원 시스템

### 2.1 개요

```
목적: 데이터베이스를 정기적으로 로컬에 백업하여
      데이터 손실/손상 시 빠른 복원 가능

백업 범위:
- PostgreSQL 전체 데이터베이스
- 파일 저장소 (S3/로컬 사진)
- 설정 파일

백업 방식:
- 전체 백업 (매일 자동)
- 증분 백업 (매시간 선택적)
- 수동 백업 (필요시)

저장 위치:
- Admin PC 로컬 (외장HDD 권장)
- 선택적: 클라우드 (Google Drive, Dropbox)

복원 기능:
- 특정 시점으로 복원
- 선택적 테이블만 복원
- 롤백 및 검증
```

### 2.6 백업 정책 (Best Practice)

```

   - 저장 위치: 로컬 SSD (빠름)

   - 보유 기간: 90일
   - 저장 위치: 외장 HDD (용량)

3️⃣ 월간 백업 (매월 1일 04:00)
   - 보유 기간: 1년
   - 저장 위치: 클라우드 (Google Drive)
   - 목적: 장기 보존

4️⃣ 테스트 복원 (매 분기)
   - 목적: 백업 무결성 검증
   - 일정: 분기마다 1회
   - 장소: 테스트 환경

복원 시나리오별 계획:
- 최근 데이터 손실: 일일 백업으로 복원 (24시간 이내 손실)
- 테이블 손상: 테이블별 선택 복원
- 전체 시스템 장애: 월간 백업으로 전체 복원 (1개월 이내)
```
