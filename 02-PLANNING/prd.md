# 마사지/스파 통합 업무자동화 플랫폼 - PRD
**Phase 2: Product Requirements Definition | Date: 2026-05-05**

---

## 1. 제품 개요 (Product Overview)

### 1.1 제품명 & 슬로건
**"ElSpa Manager"** - 마사지/스파 비즈니스를 위한 올인원 자동화 플랫폼

- **슬로건**: "채널에서 정산까지, 자동으로 연결하다"
- **핵심가치**: 자동화(Labor↓) + 통합(Error↓) + 가시성(Insight↑)

### 1.2 사용자 (User Personas)

| 역할 | 세부역할 | 주요 니즈 | 사용 빈도 |
|------|--------|---------|---------|
| **Owner** | 사업가 | 매출/수익률 리포팅, 직원관리 | 1회/일 |
| **Manager** | 현장관리자 | 스케줄 최적화, 실시간 상황파악 | 상시 |
| **Therapist** | 테라피스트 | 예약 확인, 고객정보 | 상시 |
| **Receptionist** | 예약담당자 | 상담, 예약관리, 정산 | 상시 |
| **Driver** | 드라이버 | 픽드랍 요청, 경로 최적화 | 필요시 |

### 1.3 제품 범위 (Scope)

#### ✅ IN Scope (MVP)
- 다중채널 상담 통합 (메신저, 카톡, 전화 기록)
- 자동 상담→예약 이관
- 실시간 룸/테라피스트 스케줄 뷰
- 자동 결제/정산 (구글시트 기반)
- 직원 신상/경고 기록 관리
- 야간 AI 자동상담 (기본)
- 픽드랍 자동 드라이버 배정

#### ❌ OUT of Scope (v2.0+)
- 마케팅 플랫폼 자동 감지/업그레이드 (복잡도 높음)
- 고급 분석 & 예측 (데이터 축적 필요)
- 모바일 앱 (웹 먼저)
- 블록체인/결제게이트웨이 (별도 협의)

## 2. 핵심 기능 (Features)

### 2.1 Module 1: 채널 통합 & 상담 관리

#### Feature 1.1: 다중채널 수집
```
입력:  메신저(Messenger) / 카톡(KakaoTalk) / 전화(Call Log) / 이메일 / 웹폼
처리:  API Gateway → 정규화 (통일된 형식)
출력:  상담 대시보드 (통합 뷰)
```

**요구사항:**
- [ ] 메신저 API 통합 (Facebook/Instagram)
- [ ] 카톡 API 통합 (KakaoTalk, 또는 웹훅)
- [ ] 전화 기록 자동 수집 (PBX 연동 또는 수동 업로드)
- [ ] 통합 상담함 (모든 채널 메시지 한곳에서 관리)

#### Feature 1.2: AI 자동상담 (야간/새벽)
```
고객 문의 (새벽 2시)
    ↓
AI 상담 에이전트 (즉시 응답)
    ├─ "안녕하세요! 예약하시겠어요?"
    ├─ 원하는 시간/서비스 수집
    └─ 예약 생성 (담당자 확인 대기)
    ↓
담당자 (아침 9시 확인)
    ├─ AI 예약 리뷰
    └─ 승인 또는 거절
```

**요구사항:**
- [ ] LangChain + Claude API 기반 상담 에이전트
- [ ] 24/7 자동응답 (인간 개입 없음)
- [ ] 오류 처리: 예약 불가 시 "담당자 후속" 메시지
- [ ] 일일 통계: 응답건수, 예약전환율 추적

### 2.2 Module 2: 예약 & 스케줄 관리

#### Feature 2.1: 자동 예약 이관
```
상담 → 정보추출 → 자동예약 생성 → 고객 확인 → 확정
```

**요구사항:**
- [ ] 채널→DB 자동 이관 (메신저/카톡 텍스트 파싱)
- [ ] 중복 예약 방지 (고객 ID + 시간대 체크)
- [ ] 불완전 정보 자동 보완 (예: 전화번호 미입력 시 → 담당자 리뷰)
- [ ] 고객 승인/거절 피드백 (원채널로 회신)

#### Feature 2.2: 실시간 스케줄 뷰 (통합 캘린더)
```
┌─────────────────────────────────────────────────┐
│  일시: 2026-05-05 (월)                            │
├─────────────────────────────────────────────────┤
│  09:00   [룸A] 김××님 (60min, 스웨디시)          │
│  09:30   [룸B] 이××님 (90min, 핫스톤)            │
│  10:00   [룸C] (빈 상태)                        │
│  ...                                            │
│  [테라피스트 가용성]                              │
│  - 김테라: 09:00~12:00 가능                      │
│  - 이테라: 13:00~18:00 가능                      │
│  - 박테라: OFF (요청 중)                         │
└─────────────────────────────────────────────────┘
```

**요구사항:**
- [ ] 룸별 시간대 뷰 (일/주/월)
- [ ] 테라피스트 시간대 뷰 (상태: 진행중/가능/휴식/OFF)
- [ ] 자동 충돌 감지 (룸 중복, 테라피스트 중복)
- [ ] 드래그앤드롭 재스케줄링 (긴급 변경)
- [ ] 모바일 반응형 (매니저가 외출 중에도 확인 가능)

### 2.3 Module 3: 결제 & 정산

#### Feature 3.1: 자동 정산 (구글시트 연동)
```
고객 결제 (서비스 완료 후)
    ↓
수금액 DB 기록 (자동)
    ↓
[일일 정산 (자동, 새벽 1시)]
    ├─ 총 매출 집계
    ├─ 테라피스트별 매출
    ├─ 비용(인건비/재료비) 차감
    └─ 순이익 계산
    ↓
구글시트 자동 업로드
    ↓
Owner 리포팅 (아침 7시 알람)
```

**요구사항:**
- [ ] 거래 자동 기록 (현금, 카드, 계좌이체)
- [ ] 수금 추적 (미수금 alert)
- [ ] 정산 스케줄 자동화 (매일 새벽 1시)
- [ ] 구글시트 API 연동 (자동 업로드)
- [ ] 세금 보고 자동화 (VAT 계산 등, v2.0+)

#### Feature 3.2: 비용 관리
```
직원 급여 (정기)
    ↓
결제 알람 (매월 1일)
    ├─ "김철수 급여 지급 예정: 3,000,000원"
    └─ 확인 → 자동 지급 요청
```

**요구사항:**
- [ ] 정기 비용 자동 알람
- [ ] 비용 카테고리 (인건비, 재료비, 임차료 등)
- [ ] 비용 추적 & 리포팅

## 3. 기술 요구사항

### 3.1 비기능 요구사항 (NFR)

| 속성 | 요구사항 | 목표 |
|------|---------|------|
| **가용성** | 24/7 가동 (AI 상담 포함) | 99.5% uptime |
| **응답시간** | 상담 API <1s, 스케줄 <2s | P95 기준 |
| **동시성** | 50 concurrent users | 무중단 |
| **데이터** | 일 5000 거래, 월 200건 예약 | 확장 가능 |
| **보안** | 고객/직원 정보 암호화, 접근제어 | GDPR 준수 |
| **감시** | 모든 거래/변경 로깅 | 감시추적 가능 |

### 3.2 통합 대상 (External Systems)

| 시스템 | 목적 | API | 우선순위 |
|--------|------|-----|---------|
| **Facebook/Instagram Messenger** | 상담 수집 | Graph API | P1 |
| **카카오톡** | 상담 수집 | Kakao API | P1 |
| **Google Sheets** | 정산 기록 | Sheets API | P1 |
| **Google Maps** | 거리 계산 (드라이버) | Distance Matrix API | P2 |
| **Stripe/Toss** | 결제 게이트웨이 | Payment API | P3 (v1.5+) |

## 4. 성공 기준 (Acceptance Criteria)

### 4.1 기능 AC

| Feature | AC | 기준 |
|---------|----|----|
| 자동 상담 이관 | 누락률 < 1% | 일일 상담수 vs 예약수 |
| 자동 정산 | 수동시간 90% ↓ | 정산 소요시간 |
| 스케줄 뷰 | 중복예약 0건 | 월간 불일치 |
| 야간 상담 | AI 응답률 > 80% | 성공한 상담건수 |

### 4.2 기술 AC

| 속성 | AC | 측정방법 |
|------|----|----|
| 가용성 | 99.5% uptime | 월간 가동시간 |
| 응답시간 | P95 < 2s | 로그 분석 |
| 동시성 | 50 users 무중단 | 부하테스트 |
| 데이터 일관성 | 거래 불일치 0건 | 일일 감시 |
